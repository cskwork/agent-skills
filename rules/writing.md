# Writing

- 사람에게 보여 줄 답변, 문서, 보고서, Jira 댓글, PR 설명의 문장을 작성하거나 다듬을 때 `humanizer`를 기본으로 사용한다. 지침은 `~/.agents/skills/humanizer/SKILL.md`를 읽는다.
- 사용자가 지정한 문체와 프로젝트의 문서 형식을 우선한다. 기술 문서는 중립적이고 명확하게 쓴다.
- `unslop`이나 다른 일반 문체 교정 스킬을 자동으로 겹쳐 적용하지 않는다. 사용자가 특정 스킬을 요청하면 그 요청을 따른다.
- 문장을 고쳐도 사실, 수치, 날짜, 검증 범위, 코드, 식별자, 명령과 링크를 바꾸지 않는다. 없는 근거를 보태지 않는다.
- 일반 답변·문서 작성에서는 Humanizer의 embedded mode를 사용해 최종 문안만 제공한다. 교정 과정이나 초안 비교는 사용자가 요청할 때만 보여준다.
- 문체 교정은 도메인 규칙, 사실 확인, 보안·승인 조건, Jira ADF 같은 출력 형식을 대체하지 않는다.
