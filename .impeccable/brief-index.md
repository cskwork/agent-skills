# Surface brief: index.html (landing page)

Scope: the public landing page for cskwork/agent-skills, one static file at the repo root served by GitHub Pages. Visitor mode: Persuade.

Audience and job: the owner on a fresh machine, and developers who found the repo, deciding in seconds whether to run the install line. Action: copy `npx skills add cskwork/agent-skills -g -a claude-code codex opencode -s '*' -y`. Proof: the 23 real skills with their real descriptions, and the owner's own 90-day usage counts labeled as the owner's. Constraints: no build step, no external JS, no invented claims (no stars, downloads, testimonials).

Memorable moment: the board fills. Silhouettes only until the install line is hovered or pressed; then tools drop onto their hooks one by one.

Unresolved: OG image, custom domain.

## Direction contract

THESIS: A workshop shadow board. Every skill is a tool with a painted outline; install is the moment tools hang on the hooks. Refuses the dark gradient hero plus feature-card grid.

OWN-WORLD: Off-white perforated hardboard with a visible hole lattice, black shadow paint, a red steel chest rail, stencil-ink labels, one lit element. Display in Big Shoulders Display, body in Archivo, commands in Martian Mono. Recognizable with all text removed by the hole grid and black silhouettes.

STORY: This is one repo of tools; on my machine they hang here; one line hangs them.

FIRST VIEWPORT: Red steel rail across the top, name embossed left, install line as an engraved plate right, the only glowing element. Beneath, the pegboard fills the viewport with 23 black tool silhouettes on the lattice at one shared scale, each stenciled with its skill name; primary action is the plate's copy button.

FORM: Workshop shadow board, candidate 6 of 7 on the ordered list, seed key f53073f0. Raised: lattice as grid (teletext), materials with light (raku), one scale one baseline (botanical), one lit element (neon).

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance.
