Three drawers. Pull the one you need.

  • core14 skills · the default set

    The verification loop, diagnosis, release, delegation, browser QA, the SDLC gates and the writing tools. What a working machine needs on day one.

    ./install.sh -p core
  • all23 skills · everything on the board

    Every tool above, including the image, Naver, Stream Deck and PM tools.

    ./install.sh -p all
  • third-party17 external repos · installed alongside

    The skills I use that live in other people's repos, and in my own standalone ones. One flag pulls them with the same installer.

    ./install.sh -p all -t

Shop rules.
Three of them.

No per-harness copies, no sync daemon. The clone is where you edit; the harnesses only ever hold what the repo holds.

  1. Hang the board

    On any machine, after gh auth login if you also want the private companion. The installer clones into ~/.agents/sources/cskwork/agent-skills and links each harness to it.

    npx skills add cskwork/agent-skills -g -a claude-code codex opencode -s '*' -y

  2. Edit in the clone, push

    A skill is a folder with a SKILL.md. Change it where the clone lives, commit, push. Nothing else to keep in step.

    cd ~/.agents/sources/cskwork/agent-skills && git commit -am "unslop: tighter" && git push

  3. Update everywhere else

    Same command on every other machine. Work-only tools hang on the private board, agent-skills-private, whose installer pulls this one first.

    npx skills update -g
